# betaPOS

Build-uri beta ale aplicației Gesto Terminal (POS), pentru terminalele de test.

Ultimul build, mereu la același link:

https://github.com/Touch-Vectron/betaPOS/releases/download/latest/betaPOS_latest.apk

Instalare pe un terminal Android: deschide linkul în browserul terminalului, descarcă
fișierul și permite instalarea din surse necunoscute când o cere Android-ul. O versiune
nouă se instalează peste cea veche; setările și datele rămân.

Build-uri de test, nu pentru producție.
